# Prompt examples

These examples fill the inputs only. They intentionally do not include fake API
numbers. A real run must populate every observed value from its own coverage receipt.

| Prompt | Example inputs | Expected decision artifact |
|---|---|---|
| Site Explorer | domain `plumbing.example.com`; United States/English; 15 tasks; 1,000 rows | Existing-page upside list plus cannibalization register; partial label if capped |
| Keyword Research | seed `emergency plumber`; offer `24-hour residential plumbing`; homeowners; Chicago/English | One owner per intent cluster with upgrade/create/consolidate/hold build order |
| Content Gap | my domain plus three named local competitors; 20 tasks; 1,500 rows | Relevant two-competitor gaps, cut log, actual-SERP teardowns, owner actions |
| Technical Audit | domain; 2,000-page crawl cap; 15 tasks; 10-minute wait | Verified defects, affected URLs, false-positive register, repair verification |
| AI Visibility | brand/domain; two competitors; 40 frozen buyer prompts | Mentions versus linked citations by engine, source winners, falsifiable rerun plan |
| Community Demand | topic `heat pump replacement`; homeowners; local forums plus Reddit; 30 pages | Theme/source matrix and at most one reviewed owned-page brief per intent |
| Owner Intent Map | site inventory plus candidate city/service matrix and approved fact sources | HTML report plus JSON for gold page, 10-page pilot, collisions, and holds |

## Example evidence statement

```text
OBSERVED: The API returned 842 rows from a requested cap of 1,000 for the named
market at the recorded timestamp.

CALCULATED: 96 / 842 = 11.4% of returned rows ranked in positions 4-10.

INFERRED (medium confidence): /service-a and /service-b may compete for the same
decision because both rank for the same cluster; confirm with page content and Search
Console before consolidation.

PROPOSED: Upgrade /service-a and hold a new page until ownership is resolved.
```

The report must not rewrite that proposal as deployed, indexed, ranking, or cited.
